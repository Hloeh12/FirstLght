# 星谕公开算法独立复刻（v0.11）

> 完整接口文档：[docs/API.md](docs/API.md)

独立实现，**不是原站后端**，不依赖登录，也不调用原站受保护接口。规则来自公开客户端脚本与公开发布库；与原站服务端的逐项一致性未经核验。

## 界面

浅色玫粉主题：白底、粗黑标题、`#ff4f8b` 主色、24–30px 圆角卡片、柔和投影，参考约会 App 的「It's a match」卡片风格。

- 档案：把当前输入的完整出生信息存成命名档案（最多 8 个），一键切换；合盘页可直接用档案填入第二人
- 首页：搜索过的地点会保存为常用标签（localStorage，最多 5 个，可点选或删除）
- 「不确定出生时间」开关：强制正午排盘，并在盘面顶部提示上升/宫位仅供参考
- 顶部「快速搜索城市」支持输入联想（输入「杭州」「朝阳」直接出候选，键盘 ↑↓ 选择、Enter 确认），选中后自动回填经纬度并同步省份／城市／区县三级下拉；也可手动输入海外经纬度
- 高级选项（时区库／宫制／闰月／真太阳时）折叠
- 西方盘：**SVG 圆形本命盘**——黄道逆时针、ASC 在左 / MC 在顶 / DSC / IC 四轴标注、宫位 1–12 编号、外圈 5° 刻度、星座符号随上升正确旋转、行星自动避让、前 14 条最紧相位连线、相位图例
- 印度盘：**北印菱形盘**（12 宫固定菱形、宫位星座、行星+度数、多星自动分两列）
- 紫微盘：**传统 4×4 宫格**（按地支固定排布、四化色标、大限岁数、命宫/身宫高亮、中央汇总）
- 合盘：顶部粉色百分比卡片（八科契合度 40% 样式），下方逐项评分条
- 三盘主体先渲染，紫微通过 `/api/ziwei` 异步补齐，首屏约 85 ms
- 导出 HTML 报告使用同一套浅粉排版，适合直接打印

| 场景 | 优化前 | 优化后 |

| 全新出生日期首次 `/api/chart` | 878 ms | 270 ms |
| 重复 `/api/chart` | 878 ms | 6 ms |

| 界面完整生成（二次） | 2111 ms | 104 ms |

关键改动：行星位置一次批量计算并同时供西方盘/印度盘使用（原先各算一遍）；紫微 iztro 结果单独缓存；启动时用 3 组样例预热天文与 iztro 的惰性初始化（约 2.5 s，仅启动一次）；`skipZiwei: true` 可跳过紫微进一步降到约 30 ms。

机制：盘面结果 TTL 缓存（10 分钟，按输入哈希）、时间轴独立缓存、响应 gzip、`x-compute-ms` 头、`POST /api/cache/clear` 清空。

## 农历输入与自检

- `calendar: "lunar"` + `leapMonth`：农历转公历（1900–2100 压缩表），实测与等价公历结果同 UTC、同上升
- `GET /api/validate`：11 项算法自检（二分二至黄经偏差 <0.05°、宫头单调、大运 120 年、分盘范围、农历往返等）
- Web 控制台新增「历法 / 闰月」与「运行算法自检」按钮

## 时区与结构分析

- `city.tzName` 支持 IANA 时区，直接读取 ICU 历史夏令时（1988-07 上海＝UTC+09:00，已测试）
- `houseSystem` 支持 `placidus / whole / equal / porphyry`
- `analysis` 输出庙旺落陷、命主星、元素与模式计数、大三角 / T 三角 / 星群
- Web 控制台新增「下载 Markdown / HTML」与「刷新历史」按钮

## 已实现

**西方**：astronomy-engine 星历、十行星与南北交点、Placidus（|lat|>66° 或迭代失败回退 Porphyry）、五类相位（容许度 8/5/6/6/8）、逆行、H1–H12 谐波盘。

**印度**：Lahiri 线性岁差、恒星黄道整宫、27 星宿与 Pada、Vimshottari 120 年大运、D2/D3/D4/D7/D9/D10/D12/D60。

**紫微**：`iztro@2.6.3` 生成十二宫、命主身主、五行局、主辅杂曜与四化；流年通过 `horoscope`。

**合盘**：互相位、Composite、Davison、Ashtakoota 36 分制（八项含分值与说明）。

**校正**：1986–1991 中国夏令时；真太阳时＝标准时＋经度修正＋均时差，仅作用于紫微时辰索引。

**每日运势 / 能量场**：公开前端的 hash32+mulberry32 与脉轮评分公式。

**本地模板报告**：复现公开客户端断网兜底逻辑（字段+固定文案），标记 `kind: local-template`。

## 时间轴实现口径

公开前端图例写明：过运＝木星/土星对本命日、月、上升、中天的合/刑/拱/冲；共振＝跨体系事件落在 14 天内。本项目按此实现：

1. 8 天采样 + 二分法定位精确过运时刻（前后两次采样符号变化）
2. 紫微大限按 `palaces[].decadal.range` 虚岁换算公历年
3. 紫微流年按 `horoscope(year).yearly.index` 映射宫位
4. 把西方过运、印度大运起点、紫微大限/流年切换事件合并排序，14 天内跨体系事件聚为共振窗口

窗口聚合与强弱标注是本地实现，**不等于原站后端**。
